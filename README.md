# fita-web

Public website of Fita.

## Layout

```
src/pages/       pages
src/components/  shared components
public/          logo and static assets
```

## Local preview

```sh
npm ci
npm run dev
```

## Rules

- Product facts must match the documentation in fita-docs.
- No customer names, logos or data without written permission.
- No secrets or form endpoints with keys in the code. Use environment variables at build time.
